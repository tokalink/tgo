ConnectRPC Protocol Documentation & Testing

TGo builds upon the Connect protocol, combining high-speed Protobuf binary encoding with clean JSON interoperability over standard HTTP/1.1 and HTTP/2.

Universal Client: Works natively with fetch(), curl, and native gRPC clients.
Zero Code Bloat: Type-safe Go server stubs generated directly via craft proto:gen.
Wails In-Memory IPC: Replaces browser HTTP roundtrips with direct 0.006ms memory transport in desktop builds.
